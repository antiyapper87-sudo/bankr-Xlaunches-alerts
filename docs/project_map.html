bankr-Xlaunches-alerts

Telegram-бот для мониторинга ранних запусков токенов на Base. Он собирает новые пары из Bankr, Clanker, Virtuals, DexScreener и CoinGecko, применяет жесткие фильтры, сохраняет состояние в БД, обогащает токены market/social/spoof research и отправляет компактные сигналы пользователям в Telegram.

Сводка

5источников новых запусков
21основная таблица / ledger
4Alembic-миграции
14регрессионных тестов в текущем suite

Главная задача

Поймать свежий Base launch раньше шума, но не отправлять слабые или неподтвержденные токены как сильные сигналы.

Base Telegram Early launch scanner

Текущий стек

Python async, SQLAlchemy async, Alembic, Redis/RQ, Telegram polling, SocialData, приватный Nitter, DexScreener, GeckoTerminal, CoinGecko.

Production shape

VM + systemd: bot, worker, private Nitter, Nitter Redis, firewall. Postgres/Redis для прод-состояния и очередей.

Коротко: правила бота и агента

Hermes source of truth лежит в корне проекта: identity.md, agents.md, memory.md.

Бот

  • Детерминированный Base launch scanner.
  • Источники: Bankr, Clanker, Virtuals, DexScreener, CoinGecko.
  • Один contract address = одна запись launch.
  • Слабые токены уходят в recheck / expire, а не форсятся в сигнал.

Первичные фильтры

  • Market cap от 50K.
  • 24h volume от 30K.
  • Liquidity от 30K для DEX-sourced токенов.
  • Bankr / Clanker / Virtuals пропускают liquidity check как launchpad/bonding sources.

X / Social

  • SocialData — основной квалифицированный источник.
  • Минимум 5 qualified tweets.
  • Твит режется при okai.hk/alpha, views < 50 или likes < 5.
  • Для scoring CA валидируется отдельно; ticker-only твиты не подтверждают контракт.
  • Кнопка X Research может открывать ручной поиск CA OR $TICKER.
  • Nitter — fallback discovery, не scoring source.

Агент

  • Консервативный Base launch analyst.
  • Работает только поверх уже отфильтрованного evidence.
  • Не переопределяет hard filters промптом.
  • Не хайпит и не выдумывает факты; выводит WAIT / WATCH / AVOID-style кратко.

Фильтры, Verdict 2.0 и риски

Market filters

  • MIN_MCAP: 50K.
  • MIN_VOLUME_24H: 30K.
  • MIN_LIQUIDITY: 30K для DEX-sourced.
  • Freshness/age учитывается для новых пар.

Verdict 2.0

  • services/verdict_v2.py.
  • Market, deployer, social, spoof, narrative scoring.
  • AI пока stub; детерминированный evidence главный.
  • Сохраняется в verdict_v2.

Spoof detector

  • services/spoof_detector.py.
  • Fresh same-ticker pairs, прошедшие фильтры.
  • Prior same-ticker launches, прошедшие фильтры.
  • Volume/liquidity imbalance.

Research pipeline

  • services/research_pipeline.py.
  • Source, market, deployer, wallet, flags snapshot.
  • Статусы pending / in_progress / completed / failed.

X / SocialData / Nitter

SocialData — единственный источник, который может дать qualified social evidence, потому что для наших правил нужны views/likes. Nitter помогает найти твиты, но без SocialData-verification не повышает score.

Telegram UX

Сигнальная карточка

  • Источник, token name, ticker.
  • Age, market cap, volume, liquidity, 1h change.
  • Why surfaced / AI brief stub / score.
  • Risks: same-ticker, unresolved deployer, spoof signals.

Inline buttons

  • X Research.
  • Worth watching / Skip.

Delivery model

  • Пользователь подписывается через /start в DM.
  • Один signal fanout на tenants.
  • Delivery retry ledger сохраняется в БД.

Research UX

  • /research <ticker|ca>.
  • Тот же компактный стиль, что в сигналах.
  • Social block показывает только qualified tweets.

select provider, endpoint, count(*) calls, sum(cost_units) units
from api_budget_events
where created_at > now() - interval '1 hour'
group by provider, endpoint
order by units desc;

from bot_state
